1. Vector, Parametric & Symmetric Equations of Lines

In three-dimensional space ($mathbb{R}^3$), a line cannot be described by a single scalar equation like $y = mx + b$. Instead, determining a straight line requires two essential geometric ingredients: a known point $P_0(x_0, y_0, z_0)$ through which the line passes, and a parallel direction vector $mathbf{v} = langle a, b, c angle$ specifying its orientation in space.

The Three Fundamental Representations of a 3D Line

  • Vector Equation: For any arbitrary point $P(x, y, z)$ on the line with position vector $mathbf{r} = langle x, y, z angle$ and initial point $mathbf{r}_0 = langle x_0, y_0, z_0 angle$: $$mathbf{r}(t) = mathbf{r}_0 + tmathbf{v} = langle x_0 + at,; y_0 + bt,; z_0 + ct angle, quad -infty < t < infty$$
  • Parametric Equations: Equating corresponding Cartesian components: $$egin{aligned} x &= x_0 + at \ y &= y_0 + bt \ z &= z_0 + ct end{aligned} qquad (-infty < t < infty)$$ The constants $a, b, c$ are the direction numbers of the line.
  • Symmetric Equations: If none of $a, b, c$ is zero, eliminating the scalar parameter $t = rac{x-x_0}{a} = rac{y-y_0}{b} = rac{z-z_0}{c}$ gives: $$ rac{x - x_0}{a} = rac{y - y_0}{b} = rac{z - z_0}{c}$$

Special Case: Zero Denominators in Symmetric Equations

If one (or two) of the direction numbers is zero, division by zero is undefined. The corresponding coordinate remains strictly constant:

  • If $b = 0$ while $a, c e 0$: The line is parallel to the $xz$-plane and is restricted to the plane $y = y_0$: $$ rac{x - x_0}{a} = rac{z - z_0}{c}, qquad y = y_0$$
  • If $a = 0$ and $b = 0$ ($c e 0$): The line is vertical (parallel to the $z$-axis), written simply as: $$x = x_0, qquad y = y_0$$

KFUPM Exam Shortcut: Extracting Direction from Non-Standard Numerators

In standard symmetric form, the coefficients of $x, y, z$ in the numerators must all be exactly $+1$. When a test question writes expressions like $ rac{2 - 3x}{6} = rac{1 - y}{4} = z$, apply the golden quotient rule:

$$v_i = rac{ ext{Denominator}}{ ext{Coefficient of Variable in Numerator}}$$
  • For $ rac{2 - 3x}{6}$: The variable coefficient is $-3$, denominator is $6 implies v_x = rac{6}{-3} = -2$.
  • For $ rac{1 - y}{4}$: The variable coefficient is $-1$, denominator is $4 implies v_y = rac{4}{-1} = -4$.
  • For $z = rac{z - 0}{1}$: Denominator is $1$, variable coefficient is $+1 implies v_z = rac{1}{1} = 1$.

Thus the true direction vector is $mathbf{v} = langle -2, -4, 1 angle$.

Line Passing Through Two Points & Line Segments

  • Line Through Points $P_1(x_1, y_1, z_1)$ and $P_2(x_2, y_2, z_2)$: The direction vector is the displacement vector between them: $$mathbf{v} = overrightarrow{P_1 P_2} = langle x_2 - x_1,; y_2 - y_1,; z_2 - z_1 angle$$ Either $P_1$ or $P_2$ serves as the base point $(x_0, y_0, z_0)$.
  • Parametrization of a Finite Line Segment: To describe only the segment connecting $mathbf{r}_0$ to $mathbf{r}_1$, restrict the parameter $t$ to the unit interval $[0, 1]$: $$mathbf{r}(t) = (1 - t)mathbf{r}_0 + tmathbf{r}_1, qquad 0 le t le 1$$ At $t = 0$, $mathbf{r}(0) = mathbf{r}_0$; at $t = 1$, $mathbf{r}(1) = mathbf{r}_1$; and at $t = rac{1}{2}$, $mathbf{r}(1/2)$ gives the exact midpoint.

2. Relative Positions of Two Lines in Space

In the Euclidean plane $mathbb{R}^2$, two distinct lines must either intersect or be parallel. In three-dimensional space $mathbb{R}^3$, there is a crucial third possibility: two lines can pass each other in different planes without intersecting and without being parallel. Such lines are called skew lines.

The Four Geometric Relationships Between Lines $L_1$ and $L_2$

Relationship Direction Vectors ($mathbf{v}_1, mathbf{v}_2$) Intersection Points Coplanar?
1. Parallel ($L_1 parallel L_2$) Proportional: $mathbf{v}_1 = cmathbf{v}_2$ ($c e 0$) None ($0$ points) Yes (coplanar)
2. Coincident (Identical) Proportional: $mathbf{v}_1 = cmathbf{v}_2$ Infinitely many Yes (same line)
3. Intersecting Not proportional ($mathbf{v}_1 parallel mathbf{v}_2$) Exactly one point $(a, b, c)$ Yes (coplanar)
4. Skew Lines Not proportional ($mathbf{v}_1 parallel mathbf{v}_2$) None ($0$ points) No (non-coplanar)

Angle Between Two Lines

The acute angle $ heta in [0, pi/2]$ between two lines $L_1$ and $L_2$ is determined solely by their direction vectors $mathbf{v}_1$ and $mathbf{v}_2$:

$$cos heta = rac{|mathbf{v}_1 cdot mathbf{v}_2|}{|mathbf{v}_1|,|mathbf{v}_2|}$$

In particular, two lines are orthogonal (perpendicular) ($L_1 perp L_2$) if and only if $mathbf{v}_1 cdot mathbf{v}_2 = 0$. Note: perpendicular lines in $mathbb{R}^3$ do not need to intersect; they can be perpendicular and skew!

3. The 4-Step Golden Algorithm: Finding Intersection of Two Lines

Testing whether two lines intersect and finding their common coordinates $(a, b, c)$ is one of the highest-yield questions on KFUPM Exam 2 (e.g. Terms 253, 251, 242). Following this systematic 4-step algorithm guarantees 100% accuracy and eliminates algebraic traps.

The Complete 4-Step Intersection & Skew Algorithm

  1. Step 1: Assign Distinct Parameters. Never use the same parameter letter $t$ for both lines! Parameterize $L_1$ using $t$ and $L_2$ using $s$: $$L_1: langle x_1(t), y_1(t), z_1(t) angle, qquad L_2: langle x_2(s), y_2(s), z_2(s) angle$$
  2. Step 2: Build a $2 imes 2$ System from Two Coordinates. Equate $x_1(t) = x_2(s)$ and $y_1(t) = y_2(s)$ (or any convenient pair). Solve this system for the unique parameter pair $(t^*, s^*)$.
  3. Step 3: Test Consistency in the Third Coordinate ($z$). Substitute $t^*$ into $z_1(t)$ and $s^*$ into $z_2(s)$:
    • If $z_1(t^*) = z_2(s^*)$: The system is consistent. The lines intersect!
    • If $z_1(t^*) e z_2(s^*)$: The system has no solution. The lines are skew!
  4. Step 4: Compute the Intersection Point $(a, b, c)$. If they intersect, plug $t^*$ into $L_1$ (or $s^*$ into $L_2$) to obtain $(a, b, c) = (x_1(t^*), y_1(t^*), z_1(t^*))$. Finally, compute the required exam target, such as $abc$ or $a + b + c$.

Worked Example 1: Finding Point of Intersection Between Two Lines $(a, b, c)$

Target: Coordinate Product $abc$ • Frequency: High-Yield Classic
Problem Statement

If $(a, b, c)$ is the point of intersection between the lines:

$$L_1: x = 2 + 4t, quad y = 3, quad z = 1 - t$$ $$L_2: x = 2 + 2s, quad y = 3 + 2s, quad z = 1 + s$$

then find the product $abc$.

Final Answer

Final Answer: $(a, b, c) = (2, 3, 1) implies abc = (2)(3)(1) = mathbf{6}$

Step-by-Step Solution
1 Equate Coordinates to Set Up the Linear System

At the intersection point $(a, b, c)$, all three coordinate pairs must simultaneously agree:

$$egin{cases} 2 + 4t = 2 + 2s & ext{--- (1) } [x ext{-coord}] \ 3 = 3 + 2s & ext{--- (2) } [y ext{-coord}] \ 1 - t = 1 + s & ext{--- (3) } [z ext{-coord}] end{cases}$$
2 Solve for Parameters $s$ and $t$

From equation (2), the $y$-coordinate on $L_1$ is constant at $3$:

$$3 = 3 + 2s implies 2s = 0 implies s = 0$$

Substitute $s = 0$ into equation (3):

$$1 - t = 1 + 0 implies 1 - t = 1 implies t = 0$$
3 Verify Consistency in the Remaining Coordinate ($x$)

Plug $t = 0$ and $s = 0$ into equation (1):

$$x_1(0) = 2 + 4(0) = 2, qquad x_2(0) = 2 + 2(0) = 2 quad checkmark ext{ (Consistent!)}$$

Because all three equations are satisfied, the lines intersect at a unique single point.

4 Extract $(a, b, c)$ and Calculate Target Product $abc$

Evaluating $L_1$ at $t = 0$ gives:

$$a = 2 + 4(0) = 2, quad b = 3, quad c = 1 - 0 = 1 implies (a, b, c) = (2, 3, 1)$$

Therefore, the product is:

$$abc = (2)(3)(1) = 6$$

4. Line Perpendicular to a Given Plane

A ubiquitous KFUPM question asks for the parametric equations of a line passing through a given point $P_0(x_0, y_0, z_0)$ that is perpendicular (orthogonal) to a plane $Ax + By + Cz = D$ (e.g. Terms 252, 243, 233).

Geometric Principle: Plane Normal is the Line Direction

Recall that the coefficients of $x, y, z$ in the plane equation $Ax + By + Cz = D$ define its normal vector:

$$mathbf{n} = langle A, B, C angle perp ext{Plane}$$

Since the desired line $L$ is perpendicular to the plane, $L$ must point in the exact same direction as the normal vector $mathbf{n}$. Therefore, we set the line's direction vector $mathbf{v}$ directly equal to $mathbf{n}$ (or any non-zero scalar multiple):

$$mathbf{v}_{ ext{line}} = mathbf{n}_{ ext{plane}} = langle A, B, C angle$$

The resulting parametric equations are:

$$x = x_0 + At, qquad y = y_0 + Bt, qquad z = z_0 + Ct$$

Watch Out for Fixed Coefficient Matching Traps!

In Term 252 Q1, the problem specified: "parametric equations are $x = 2 + at, y = 3 + bt, z = 4 - t$."

Notice that the coefficient of $t$ in $z$ was fixed as $-1$. If the plane normal is $mathbf{n} = langle 3, 2, -1 angle$, the $z$-component already matches $-1$ ($k = 1$), so $a = 3$ and $b = 2$. However, if the plane normal had been $langle 6, 4, -2 angle$, you would need to divide by $2$ to match the required $z$-coefficient of $-1$ before reading off $a$ and $b$!

Worked Example 2: Determining Whether Two Lines are Parallel, Skew, or Intersecting

Target: Full Geometric Classification & Skew Diagnosis • Type: Comprehensive Analysis
Problem Statement

Determine whether the following two lines given in symmetric form are parallel, intersecting, or skew:

$$L_1: rac{x - 2}{1} = rac{y - 3}{-2} = rac{z - 1}{-3}$$ $$L_2: rac{x - 3}{1} = rac{y + 4}{3} = rac{z - 4}{-7}$$
Final Answer

Final Answer: The lines $L_1$ and $L_2$ are skew lines (they are not parallel and do not intersect).

Step-by-Step Solution
1 Test Parallelism via Direction Vectors

Read the direction numbers directly from the denominators of the symmetric equations:

$$mathbf{v}_1 = langle 1, -2, -3 angle, qquad mathbf{v}_2 = langle 1, 3, -7 angle$$

Compare the component ratios:

$$ rac{1}{1} e rac{-2}{3} e rac{-3}{-7}$$

Because the ratios are not equal, $mathbf{v}_1$ and $mathbf{v}_2$ are not parallel. Thus, $L_1 parallel L_2$.

2 Convert to Parametric Form with Distinct Parameters

Let $t$ be the parameter for $L_1$ and $s$ be the parameter for $L_2$:

$$L_1: quad x = 2 + t, quad y = 3 - 2t, quad z = 1 - 3t$$ $$L_2: quad x = 3 + s, quad y = -4 + 3s, quad z = 4 - 7s$$
3 Solve the $2 imes 2$ System for $x$ and $y$
$$egin{cases} 2 + t = 3 + s & implies t = s + 1 \ 3 - 2t = -4 + 3s end{cases}$$

Substitute $t = s + 1$ into the $y$-equation:

$$3 - 2(s + 1) = -4 + 3s implies 3 - 2s - 2 = -4 + 3s implies 1 - 2s = -4 + 3s$$ $$5s = 5 implies s = 1$$

Then $t = s + 1 = 1 + 1 = 2$.

4 Test $z$-Consistency to Reveal Skew Lines

Compute the $z$-coordinate for each line at these candidate parameters:

$$z_1(2) = 1 - 3(2) = 1 - 6 = -5$$ $$z_2(1) = 4 - 7(1) = 4 - 7 = -3$$

Because $z_1(2) = -5 e z_2(1) = -3$, the system has no simultaneous solution. The lines neither intersect nor are parallel, proving they are skew lines.

Pedagogical Comparison: If $L_2$ had numerator $z - 2$ instead of $z - 4$, then $z_2(1) = 2 - 7(1) = -5 = z_1(2)$, and the lines would have intersected at the point $(4, -1, -5)$.

5. Intersection of a Line and a Plane (Piercing Points)

Finding the piercing point where a line penetrates a plane is a core analytical competency tested in PT1 Q1, Term 253 Q8, Term 233 Q3, and Term 221 Q2.

The Direct Substitution Algorithm

Given line $L: x = x_0 + at, ; y = y_0 + bt, ; z = z_0 + ct$ and plane $Pi: Ax + By + Cz = D$:

  1. Substitute: Insert the parametric equations for $x, y, z$ directly into the plane's linear equation: $$A(x_0 + at) + B(y_0 + bt) + C(z_0 + ct) = D$$
  2. Solve for $t$: Collect terms into $(Aa + Bb + Cc)t = D - (Ax_0 + By_0 + Cz_0)$. Note that the coefficient of $t$ is simply $mathbf{n} cdot mathbf{v}$. $$t = rac{D - (Ax_0 + By_0 + Cz_0)}{mathbf{n} cdot mathbf{v}}$$
  3. Back-Substitute: Insert the resulting $t^*$ value back into the line equations to obtain the exact Cartesian coordinates $(a, b, c) = (x(t^*), y(t^*), z(t^*))$.

Geometric Classification by Parameter Roots

  • Case 1: $mathbf{n} cdot mathbf{v} e 0$ (Unique Root $t^*$): The line is not parallel to the plane and pierces it at exactly one unique point.
  • Case 2: $mathbf{n} cdot mathbf{v} = 0$ and LHS $ e$ RHS (Contradiction $0t = k e 0$): The line is strictly parallel to the plane and never touches it ($0$ intersection points).
  • Case 3: $mathbf{n} cdot mathbf{v} = 0$ and LHS $=$ RHS (Identity $0t = 0$): The line lies completely embedded inside the plane ($infty$ intersection points).

6. Collinear Points in 3D Space

Three points $P, Q, R$ in $mathbb{R}^3$ are said to be collinear if they all lie along the exact same straight line. In Term 231 Q16, students were tested on finding an unknown coordinate parameter $a$ for a collinear point.

The Proportionality Condition for Collinearity

Points $P, Q, R$ are collinear if and only if the displacement vector $overrightarrow{PR}$ is a scalar multiple of $overrightarrow{PQ}$:

$$overrightarrow{PR} = k overrightarrow{PQ} quad (k e 0)$$

In Cartesian coordinates, this means all three component ratios must equal the exact same scaling constant $k$:

$$ rac{x_R - x_P}{x_Q - x_P} = rac{y_R - y_P}{y_Q - y_P} = rac{z_R - z_P}{z_Q - z_P} = k$$

Fast 3-Step Recipe to Solve Unknown Coordinate Problems

  1. Compute the known numerical components of $overrightarrow{PQ}$ and $overrightarrow{PR}$.
  2. Solve for the scalar $k$ from a coordinate where both numbers are known (e.g. $ rac{x_R - x_P}{x_Q - x_P} = k$).
  3. Set the component containing the unknown equal to $k$ and solve for the unknown parameter directly.

For the plane $3x + 2y - z = 6$, the normal vector is read directly from the coefficients of $x, y, z$:

$$mathbf{n} = langle 3, 2, -1 angle$$

$$mathbf{v} = k langle 3, 2, -1 angle = langle 3k, 2k, -k angle$$

We are given that the parametric equations are $x = 2 + at, ; y = 3 + bt, ; z = 4 - t$. Look at the $z$-coefficient:

$$v_z = -1 implies -k = -1 implies k = 1$$

Therefore, $a = 3k = 3(1) = 3$ and $b = 2k = 2(1) = 2$.

$$a + b = 3 + 2 = 5$$

$$1 = k(-1) implies k = -1$$ $$ ext{Check } y ext{-component: } -2 = (-1)(2) = -2 quad checkmark$$

$$a - 4 = k(3) = (-1)(3) = -3 implies a = -3 + 4 = 1$$

Explanation §1

1. Standard & Linear Equations of Planes & True/False Conceptual Analysis

In three-dimensional space $mathbb{R}^3$, a single direction vector is not enough to fix the tilt of a plane because an infinite family of planes can contain that same direction. Instead, a plane $Pi$ is uniquely pinned down in space by two geometric components: a known point $P_0(x_0, y_0, z_0)$ lying on the plane, and a non-zero normal vector $mathbf{n} = langle A, B, C angle$ that is strictly perpendicular (orthogonal) to every vector lying in the plane ($mathbf{n} perp Pi$).

The Equations of a Plane in 3D Space

  • Vector Equation: For any arbitrary point $P(x, y, z)$ on the plane with position vector $mathbf{r} = langle x, y, z angle$, the displacement vector $overrightarrow{P_0 P} = mathbf{r} - mathbf{r}_0$ lies completely inside $Pi$. Because $mathbf{n} perp Pi$, their dot product must vanish: $$mathbf{n} cdot (mathbf{r} - mathbf{r}_0) = 0$$
  • Scalar (Point-Normal / Standard) Equation: Expanding the dot product with $mathbf{n} = langle A, B, C angle$ and $mathbf{r} - mathbf{r}_0 = langle x - x_0, y - y_0, z - z_0 angle$: $$A(x - x_0) + B(y - y_0) + C(z - z_0) = 0$$
  • General Linear Equation: Distributing the constants and defining $D = Ax_0 + By_0 + Cz_0$: $$Ax + By + Cz = D$$ Golden Reading Rule: In any linear plane equation $Ax + By + Cz = D$, the coefficients of $x, y, z$ immediately and effortlessly provide the components of the normal vector: $mathbf{n} = langle A, B, C angle$.

KFUPM True / False Conceptual Properties (Exam Focus: Term 251 Q1 & Term 242 Q1)

  • Parallel Planes ($Pi_1 parallel Pi_2$): Two planes are parallel if and only if their normal vectors are proportional: $$ rac{A_1}{A_2} = rac{B_1}{B_2} = rac{C_1}{C_2} = k$$
  • Orthogonal Planes ($Pi_1 perp Pi_2$): Two planes are perpendicular if and only if their normal vectors are orthogonal: $$mathbf{n}_1 cdot mathbf{n}_2 = A_1 A_2 + B_1 B_2 + C_1 C_2 = 0$$
  • Planes Parallel to Coordinate Axes (Missing Variable Rule):
    • If an equation lacks the variable $z$, such as $Ax + By = D$, its normal vector is $mathbf{n} = langle A, B, 0 angle$. Notice that $mathbf{n} cdot mathbf{k} = langle A, B, 0 angle cdot langle 0, 0, 1 angle = 0$, meaning the normal is perpendicular to the $z$-axis. Therefore, the plane is parallel to the $z$-axis!
    • Similarly, $By + Cz = D$ is parallel to the $x$-axis, and $Ax + Cz = D$ is parallel to the $y$-axis.
  • Planes Parallel to Coordinate Planes:
    • $z = c$: A horizontal plane parallel to the $xy$-plane (normal $langle 0, 0, 1 angle = mathbf{k}$). In particular, $z = 0$ is the $xy$-plane.
    • $y = b$: A plane parallel to the $xz$-plane (normal $langle 0, 1, 0 angle = mathbf{j}$).
    • $x = a$: A plane parallel to the $yz$-plane (normal $langle 1, 0, 0 angle = mathbf{i}$).
  • Intercept Form of a Plane: If a plane intersects the coordinate axes at $(a, 0, 0)$, $(0, b, 0)$, and $(0, 0, c)$ with $a, b, c e 0$, its equation can be written as: $$ rac{x}{a} + rac{y}{b} + rac{z}{c} = 1$$
  • Distance from a Point $P_1(x_1, y_1, z_1)$ to Plane $Ax + By + Cz = D$: $$ ext{Dist}(P_1, Pi) = rac{|Ax_1 + By_1 + Cz_1 - D|}{sqrt{A^2 + B^2 + C^2}}$$

Classic KFUPM Exam Trap: Sign Inconsistencies in Parallelism Checks

In Term 251 Q1, students were asked which statement was FALSE about the plane $4x - y + 3z = 6$:

One choice stated: "It is parallel to the plane $8x - 2y - 6z = 10$."

Compare their normal vectors: $mathbf{n}_1 = langle 4, -1, 3 angle$ and $mathbf{n}_2 = langle 8, -2, -6 angle$. Look at the ratios:

$$ rac{4}{8} = rac{1}{2}, qquad rac{-1}{-2} = rac{1}{2}, qquad ext{BUT} quad rac{3}{-6} = - rac{1}{2} e rac{1}{2}!$$

3. Plane Containing Two Lines

When two distinct lines $L_1$ and $L_2$ lie in the same plane, the plane is called their coplanar spanning plane. As tested in Term 253 Q12, the lines can either intersect at a common point or be parallel.

1. Distance from a Point to a Plane

In three-dimensional space $\mathbb{R}^3$, the shortest (perpendicular) distance $D$ from an arbitrary point $P_0(x_0, y_0, z_0)$ to a plane $\Pi$ is measured along the straight line passing through $P_0$ that is orthogonal to the plane.

Vector Projection Derivation

Let $P_1(x_1, y_1, z_1)$ be any point lying on the plane $\Pi$, and let $\mathbf{n} = \langle A, B, C \rangle$ be the normal vector to $\Pi$. Consider the connecting displacement vector $\overrightarrow{P_1 P_0} = \langle x_0 - x_1, y_0 - y_1, z_0 - z_1 \rangle$ from the plane to the external point.

Dropping a perpendicular from $P_0$ onto the plane forms a right triangle whose adjacent leg along the direction of $\mathbf{n}$ has length equal to the distance $D$. Hence, $D$ is precisely the absolute value of the scalar component of $\overrightarrow{P_1 P_0}$ along $\mathbf{n}$:

Point-to-Plane Distance Formulas

Vector Formulation:

$$D = |\operatorname{comp}_{\mathbf{n}} \overrightarrow{P_1 P_0}| = \frac{|\overrightarrow{P_1 P_0} \cdot \mathbf{n}|}{\|\mathbf{n}\|}$$

Cartesian Coordinate Formulation: For a plane with general equation $Ax + By + Cz + D_0 = 0$ (or $Ax + By + Cz = D$):

$$D = \frac{|Ax_0 + By_0 + Cz_0 + D_0|}{\sqrt{A^2 + B^2 + C^2}} = \frac{|Ax_0 + By_0 + Cz_0 - D|}{\sqrt{A^2 + B^2 + C^2}}$$
! Critical Exam Trap • Absolute Value & Sign Consistency Students frequently drop the absolute value bars in the numerator and end up with a negative distance, or confuse whether the constant term $D$ is on the left-hand or right-hand side. Always verify:
  1. Standardize first: Bring the plane equation into the form $Ax + By + Cz - D = 0$.
  2. Direct evaluation: Substitute $(x_0, y_0, z_0)$ into the expression $Ax_0 + By_0 + Cz_0 - D$.
  3. Strict non-negativity: Distance $D$ must always be $\ge 0$. If $D = 0$, the point $P_0$ lies directly on the plane.

Geometric Insight: Point-Normal Form Shortcut

If the plane is already given in point-normal form $A(x - x_1) + B(y - y_1) + C(z - z_1) = 0$, you can directly evaluate the numerator by substituting $(x_0, y_0, z_0)$ into the factored left-hand side without expanding:

$$D = \frac{|A(x_0 - x_1) + B(y_0 - y_1) + C(z_0 - z_1)|}{\sqrt{A^2 + B^2 + C^2}}$$

2. Distance Between Parallel Planes & The Matching Coefficient Rule

Parallel planes never intersect and maintain a constant perpendicular separation everywhere in $\mathbb{R}^3$. Questions on finding the distance between parallel planes appear consistently in KFUPM exams (Term 253, 241, 231, 223).

! THE #1 KFUPM EXAM TRAP • UNMATCHED COEFFICIENTS

Suppose you are given two parallel planes:

$$\Pi_1: A_1 x + B_1 y + C_1 z = D_1 \qquad \text{and} \qquad \Pi_2: A_2 x + B_2 y + C_2 z = D_2$$

FATAL ERROR: Subtracting constant terms directly via $\frac{|D_1 - D_2|}{\sqrt{A_1^2 + B_1^2 + C_1^2}}$ produces an incorrect answer whenever $\mathbf{n}_1 \neq \mathbf{n}_2$!

MANDATORY RULE: You must first multiply or divide one (or both) equations by a non-zero scalar so that their normal vector coefficients $\langle A, B, C \rangle$ are 100% IDENTICAL:

$$\Pi_1: Ax + By + Cz = D_1 \qquad \text{and} \qquad \Pi_2: Ax + By + Cz = D_2$$

Only then does the rapid distance formula hold:

$$D = \frac{|D_1 - D_2|}{\sqrt{A^2 + B^2 + C^2}}$$

The Two Valid Solution Methods for Parallel Planes

  • Method A (Coefficient Matching Formula):
    1. Check parallelism: verify $\frac{A_1}{A_2} = \frac{B_1}{B_2} = \frac{C_1}{C_2} = k$.
    2. Scale one equation by $k$ so both planes share the exact same coefficients $\langle A, B, C \rangle$.
    3. Compute $D = \frac{|D_1 - D_2|}{\sqrt{A^2 + B^2 + C^2}}$.
  • Method B (Point Selection Method • Fail-Safe):
    1. Pick any convenient point $P_1$ lying on $\Pi_1$ by setting two variables to zero (e.g., $y = 0, z = 0 \implies x = D_1 / A_1$).
    2. Compute the standard point-to-plane distance from $P_1$ to the second plane $\Pi_2$.
    3. This method is completely immune to coefficient mismatch errors and requires zero memorization!

Problem Statement

Step-by-Step Solution
1

Read the normal vectors from the coefficients of $x, y, z$:

$$\mathbf{n}_1 = \langle 1, -3, 2 \rangle \qquad \text{and} \qquad \mathbf{n}_2 = \langle 2, -6, 4 \rangle$$

Notice that $\mathbf{n}_2 = 2\mathbf{n}_1$. Because the normal vectors are scalar multiples, the planes are confirmed to be strictly parallel.

2

Notice the coefficients are currently unmatched ($1 \neq 2$, $-3 \neq -6$, $2 \neq 4$). Multiply the entire equation of $\Pi_1$ by $2$:

$$2(x - 3y + 2z = 1) \implies 2x - 6y + 4z = 2$$

Now rewrite both planes side-by-side with identical normal vector $\mathbf{n} = \langle 2, -6, 4 \rangle$:

$$\Pi_1: 2x - 6y + 4z = 2 \quad (D_1 = 2)$$ $$\Pi_2: 2x - 6y + 4z = 3 \quad (D_2 = 3)$$
3

Substitute $A = 2, B = -6, C = 4, D_1 = 2, D_2 = 3$ into the distance formula:

$$D = \frac{|D_2 - D_1|}{\sqrt{A^2 + B^2 + C^2}} = \frac{|3 - 2|}{\sqrt{2^2 + (-6)^2 + 4^2}} = \frac{1}{\sqrt{4 + 36 + 16}} = \frac{1}{\sqrt{56}}$$

Simplify the radical in the denominator and rationalize:

$$\sqrt{56} = \sqrt{4 \times 14} = 2\sqrt{14} \implies D = \frac{1}{2\sqrt{14}} = \frac{\sqrt{14}}{2 \times 14} = \frac{\sqrt{14}}{28}$$
4
Alternative Verification via Point Selection Method

Pick a point on $\Pi_1: x - 3y + 2z = 1$. Setting $y = 0$ and $z = 0$ gives $x = 1$, so $P_1(1, 0, 0)$ is on $\Pi_1$.

Compute distance from $P_1(1, 0, 0)$ to $\Pi_2: 2x - 6y + 4z - 3 = 0$:

$$D = \frac{|2(1) - 6(0) + 4(0) - 3|}{\sqrt{2^2 + (-6)^2 + 4^2}} = \frac{|2 - 3|}{\sqrt{56}} = \frac{1}{\sqrt{56}} = \frac{\sqrt{14}}{28}$$

Both methods yield the exact same result with 100% certainty.

3. Distance from a Point to a Line in Space

In $\mathbb{R}^3$, lines do not have a single normal vector (there is an entire plane of orthogonal vectors perpendicular to a line). Consequently, finding the distance from a point to a line requires the cross product rather than the dot product.

Geometric Derivation via Parallelogram Area

Let $L$ be a line passing through a base reference point $P_0$ with direction vector $\mathbf{v}$. Let $Q$ be an external point not on $L$.

Consider the parallelogram formed by the displacement vector $\overrightarrow{P_0 Q}$ and the line's direction vector $\mathbf{v}$:

  • By vector definition: The area of this parallelogram equals the magnitude of the cross product: $\text{Area} = \|\overrightarrow{P_0 Q} \times \mathbf{v}\|$.
  • By elementary geometry: The area of any parallelogram equals $\text{base} \times \text{height} = \|\mathbf{v}\| \times D$, where the height $D$ is the perpendicular distance from $Q$ to the line $L$.

Equating the two expressions for area immediately produces the point-to-line distance formula:

Point-to-Line Distance Formula in $\mathbb{R}^3$

$$D = \frac{\|\overrightarrow{P_0 Q} \times \mathbf{v}\|}{\|\mathbf{v}\|}$$

where:

  • $Q$ is the given point in space.
  • $P_0$ is any point lying on the line $L$ (found by setting parameter $t = 0$).
  • $\mathbf{v}$ is the direction vector of the line $L$.
  • $\overrightarrow{P_0 Q} = Q - P_0 = \langle x_Q - x_0, y_Q - y_0, z_Q - z_0 \rangle$.

Systematic Recipe for Point-to-Line Calculations

  1. Extract parameters: Read $P_0$ and $\mathbf{v}$ from the parametric or symmetric equations of the line.
  2. Construct displacement: Compute vector $\overrightarrow{P_0 Q} = Q - P_0$.
  3. Compute cross product: Evaluate the $3 \times 3$ determinant $\overrightarrow{P_0 Q} \times \mathbf{v}$.
  4. Calculate magnitudes: Find $\|\overrightarrow{P_0 Q} \times \mathbf{v}\|$ and $\|\mathbf{v}\|$, then divide.

Problem Statement

Find the perpendicular distance between the point $Q(-2, 1, 3)$ and the line $L$ given by:

$$x = 1 - t, \quad y = 2 + t, \quad z = -2t$$
Final Answer

Final Answer: $D = \frac{7}{\sqrt{3}} = \frac{7\sqrt{3}}{3}$

Step-by-Step Solution
1
Extract Reference Point and Direction Vector from Line $L$

From the parametric equations of the line:

$$x = 1 - 1t, \quad y = 2 + 1t, \quad z = 0 - 2t$$
  • Setting $t = 0$ yields a base point on $L$: $P_0(1, 2, 0)$.
  • Reading the coefficients of $t$ gives the direction vector: $\mathbf{v} = \langle -1, 1, -2 \rangle$.
2
Construct the Displacement Vector $\overrightarrow{P_0 Q}$

Subtract the coordinates of base point $P_0$ from the target point $Q(-2, 1, 3)$:

$$\overrightarrow{P_0 Q} = Q - P_0 = \langle -2 - 1, \; 1 - 2, \; 3 - 0 \rangle = \langle -3, -1, 3 \rangle$$
3
Compute the Cross Product $\overrightarrow{P_0 Q} \times \mathbf{v}$

Set up the $3 \times 3$ determinant:

$$\overrightarrow{P_0 Q} \times \mathbf{v} = \begin{vmatrix} \mathbf{i} & \mathbf{j} & \mathbf{k} \\ -3 & -1 & 3 \\ -1 & 1 & -2 \end{vmatrix}$$

Expanding across the first row:

  • $\mathbf{i}\text{-component}: (-1)(-2) - (3)(1) = 2 - 3 = -1$
  • $\mathbf{j}\text{-component}: -[(-3)(-2) - (3)(-1)] = -[6 + 3] = -9$
  • $\mathbf{k}\text{-component}: (-3)(1) - (-1)(-1) = -3 - 1 = -4$
$$\overrightarrow{P_0 Q} \times \mathbf{v} = \langle -1, -9, -4 \rangle$$
4
Compute Magnitudes and Evaluate Distance Formula

Find the magnitude of the cross product:

$$\|\overrightarrow{P_0 Q} \times \mathbf{v}\| = \sqrt{(-1)^2 + (-9)^2 + (-4)^2} = \sqrt{1 + 81 + 16} = \sqrt{98} = \sqrt{49 \times 2} = 7\sqrt{2}$$

Find the magnitude of the direction vector $\mathbf{v}$:

$$\|\mathbf{v}\| = \sqrt{(-1)^2 + 1^2 + (-2)^2} = \sqrt{1 + 1 + 4} = \sqrt{6}$$

Divide the two magnitudes:

$$D = \frac{\|\overrightarrow{P_0 Q} \times \mathbf{v}\|}{\|\mathbf{v}\|} = \frac{7\sqrt{2}}{\sqrt{6}} = \frac{7\sqrt{2}}{\sqrt{2}\sqrt{3}} = \frac{7}{\sqrt{3}} = \frac{7\sqrt{3}}{3}$$

4. Distance Between Two Skew Lines

Two lines in three dimensions are called skew lines if they do not intersect and are not parallel. Skew lines can only exist in dimension 3 or higher. Computing the shortest distance between them is a staple KFUPM exam problem (Term 243 Q4).

Geometric Conception: Parallel Envelope Planes

Every pair of skew lines $L_1$ and $L_2$ can be enclosed in two unique parallel planes $\Pi_1$ and $\Pi_2$, where $\Pi_1$ contains $L_1$ and $\Pi_2$ contains $L_2$.

  • Because both planes are parallel to both lines, their shared normal vector $\mathbf{n}$ must be orthogonal to both direction vectors $\mathbf{v}_1$ and $\mathbf{v}_2$: $$\mathbf{n} = \mathbf{v}_1 \times \mathbf{v}_2$$
  • The perpendicular distance between the skew lines is therefore identical to the distance between these two parallel planes!

Skew Lines Distance Formula (Scalar Triple Product)

$$D = \frac{|\overrightarrow{P_1 P_2} \cdot (\mathbf{v}_1 \times \mathbf{v}_2)|}{\|\mathbf{v}_1 \times \mathbf{v}_2\|}$$

Physical Interpretation: The numerator $|\overrightarrow{P_1 P_2} \cdot (\mathbf{v}_1 \times \mathbf{v}_2)|$ is the volume of the parallelepiped spanned by $\overrightarrow{P_1 P_2}, \mathbf{v}_1, \mathbf{v}_2$. The denominator $\|\mathbf{v}_1 \times \mathbf{v}_2\|$ is the area of the base spanned by $\mathbf{v}_1$ and $\mathbf{v}_2$. Since $\text{Volume} = \text{Base Area} \times \text{Height}$, dividing gives the exact perpendicular separation $D$!

Find the shortest distance between the two skew lines:

1
Extract Reference Points and Direction Vectors

For line $L_1$ (setting $t = 0$):

$$P_1 = (0, 0, 0), \qquad \mathbf{v}_1 = \langle 2, 4, 6 \rangle$$

For line $L_2$ (setting $s = 0$):

$$P_2 = (1, 4, -1), \qquad \mathbf{v}_2 = \langle -1, 1, 1 \rangle$$

Set up and evaluate the cross product determinant:

Divide the absolute scalar triple product by the magnitude:

5. Distance Between Two Parallel Lines & The Skew Formula Failure

When two lines $L_1$ and $L_2$ are parallel, their direction vectors are scalar multiples: $\mathbf{v}_1 \parallel \mathbf{v}_2$. This creates a mathematical trap that catches many students off guard.

! DANGER • WHY THE SKEW DISTANCE FORMULA FAILS FOR PARALLEL LINES

If $\mathbf{v}_1 \parallel \mathbf{v}_2$, their cross product is the zero vector:

$$\mathbf{v}_1 \times \mathbf{v}_2 = \mathbf{0} \implies \|\mathbf{v}_1 \times \mathbf{v}_2\| = 0$$

Plugging this into the skew formula produces $\frac{0}{0}$, which is completely indeterminate and fatal on an exam!

The Correct Method for Distance Between Parallel Lines

Because parallel lines maintain a constant separation along their entire length, the distance between two parallel lines reduces to the Point-to-Line Distance:

  1. Pick any point $P_1$ on line $L_1$.
  2. Pick any point $P_2$ on line $L_2$.
  3. Form the displacement vector $\overrightarrow{P_1 P_2} = P_2 - P_1$.
  4. Apply the Point-to-Line formula using either line's direction vector $\mathbf{v}$ (since $\mathbf{v}_1 \parallel \mathbf{v}_2$):
$$D = \frac{\|\overrightarrow{P_1 P_2} \times \mathbf{v}\|}{\|\mathbf{v}\|}$$

1. Cylinders in 3D Space & The Missing Variable Rule

In three-dimensional space $\mathbb{R}^3$, the term cylinder does not refer exclusively to a circular soup can. Rather, it describes an entire family of surfaces generated by translating a straight line along a curved planar path.

Formal Definition of a Cylinder

A cylinder is a surface consisting of all lines (called rulings) that are parallel to a given fixed line and pass through a given plane curve (called the generating curve or directrix).

The Missing Variable Rule in $\mathbb{R}^3$

If an equation in three variables $(x, y, z)$ contains only two variables (one variable is missing entirely):

  • The graph in $\mathbb{R}^3$ is a cylinder.
  • Its generating curve is the 2D curve formed by the two present variables in their respective coordinate plane.
  • Its rulings are straight lines parallel to the coordinate axis of the missing variable (extending infinitely from $-\infty$ to $+\infty$).

The Three Fundamental Cylinder Archetypes

  • Parabolic Cylinder (e.g. $y = x^2$): The variable $z$ is missing. In the $xy$-plane, $y = x^2$ is a parabola. Sweeping this parabola parallel to the $z$-axis produces a trough-like parabolic sheet. Every horizontal slice $z = k$ is an identical parabola $y = x^2$.
  • Circular / Elliptic Cylinder (e.g. $x^2 + z^2 = 4$): The variable $y$ is missing. In the $xz$-plane, $x^2 + z^2 = 4$ is a circle of radius $2$. Sweeping parallel to the $y$-axis generates a circular pipe centered on the $y$-axis. Every slice $y = k$ is a circle $x^2 + z^2 = 4$.
  • Hyperbolic Cylinder (e.g. $y^2 - z^2 = 1$): The variable $x$ is missing. In the $yz$-plane, $y^2 - z^2 = 1$ is a hyperbola opening along the $y$-axis. Sweeping along lines parallel to the $x$-axis produces two separate symmetric open sheets.
! Critical Dimension Trap • $\mathbb{R}^2$ vs $\mathbb{R}^3$ Context is everything! When reading an exam problem:
  • In $\mathbb{R}^2$, the equation $x^2 + y^2 = 9$ represents a 1D circular curve.
  • In $\mathbb{R}^3$, the equation $x^2 + y^2 = 9$ represents a 2D circular cylinder extending indefinitely parallel to the $z$-axis.

2. The 6 Standard Quadric Surfaces (Origin-Centered)

A quadric surface is the three-dimensional graph of a second-degree polynomial equation in $x, y, z$. There are exactly six fundamental non-degenerate quadric surface archetypes centered at the origin $(0, 0, 0)$.

Master Comparison Table of Quadric Surfaces

Surface Name Standard Canonical Equation Distinctive Signature Traces Overview
1. Ellipsoid $\frac{x^2}{a^2} + \frac{y^2}{b^2} + \frac{z^2}{c^2} = 1$ All 3 squared terms positive; bounded solid All traces in $x=k, y=k, z=k$ are ellipses (or empty if $|k| >$ axis).
2. Elliptic Paraboloid $\frac{z}{c} = \frac{x^2}{a^2} + \frac{y^2}{b^2}$ 1 linear variable, 2 squared terms of SAME sign Horizontal slices ($z=k>0$) are ellipses; vertical slices ($x=k, y=k$) are parabolas. Opens along linear axis.
3. Hyperbolic Paraboloid
(Saddle Surface)		 $\frac{z}{c} = \frac{x^2}{a^2} - \frac{y^2}{b^2}$ 1 linear variable, 2 squared terms of OPPOSITE signs Horizontal slices ($z=k \neq 0$) are hyperbolas; vertical slices are parabolas. Saddle point at $(0,0,0)$.
4. Elliptic Cone $\frac{z^2}{c^2} = \frac{x^2}{a^2} + \frac{y^2}{b^2}$ All 3 squared, RHS $= 0$; vertex at $(0,0,0)$ Trace at $z=0$ is a single point (vertex); traces $z=k \neq 0$ are ellipses; vertical slices through vertex are intersecting lines.
5. Hyperboloid of One Sheet $\frac{x^2}{a^2} + \frac{y^2}{b^2} - \frac{z^2}{c^2} = 1$ RHS $= 1$, exactly ONE minus sign; connected waist Slices $z=k$ are ellipses (never empty); vertical slices containing symmetry axis are hyperbolas. Opens along negative variable.
6. Hyperboloid of Two Sheets $-\frac{x^2}{a^2} - \frac{y^2}{b^2} + \frac{z^2}{c^2} = 1$ RHS $= 1$, TWO minus signs; disconnected lobes Vertices at $(0,0,\pm c)$. Gap for $|z| < c$ (trace is $\emptyset$). Traces $|z| > c$ are ellipses. Opens along positive variable.

The Rapid 3-Second Classification Mnemonic

Bring the equation to canonical form where all squared terms are on the LHS and the constant is normalized to $+1$ (or linear variable isolated on LHS):

  1. Is there a linear (unsquared) variable?
    • Yes, with same signs for squared terms $\implies$ Elliptic Paraboloid.
    • Yes, with opposite signs for squared terms $\implies$ Hyperbolic Paraboloid.
  2. Are all three variables squared?
    • RHS $= 0$ $\implies$ Elliptic Cone.
    • RHS $= 1$, 0 minus signs $\implies$ Ellipsoid.
    • RHS $= 1$, 1 minus sign $\implies$ Hyperboloid of One Sheet (opens along the minus-sign axis).
    • RHS $= 1$, 2 minus signs $\implies$ Hyperboloid of Two Sheets (opens along the positive-sign axis).

3. Equidistant Loci Forming Quadric Surfaces

A premier KFUPM Exam 2 archetype asks students to derive and classify the surface formed by the set of all points in space equidistant from a fixed focal point and a given plane (Term 242 Q4, Term 233 Q15, Term 223 Q5).

General Algebraic Proof: Why Equidistant Loci Produce Paraboloids

Let $P(x, y, z)$ be an arbitrary point on the surface. Suppose $P$ is equidistant from a fixed point $F(x_0, y_0, z_0)$ and a plane parallel to a coordinate plane, say $z = d$:

  1. Euclidean distance to point $F$: $$d_1 = \sqrt{(x - x_0)^2 + (y - y_0)^2 + (z - z_0)^2}$$
  2. Perpendicular distance to plane $z = d$: $$d_2 = |z - d|$$
  3. Equate and square both sides: $$(x - x_0)^2 + (y - y_0)^2 + (z - z_0)^2 = (z - d)^2$$
  4. Expand the squared terms involving $z$: $$(x - x_0)^2 + (y - y_0)^2 + z^2 - 2z_0 z + z_0^2 = z^2 - 2dz + d^2$$

The Inevitable Paraboloid Cancellation

Notice that the $z^2$ terms on both sides cancel out identically!

$$(x - x_0)^2 + (y - y_0)^2 + 2(d - z_0)z + (z_0^2 - d^2) = 0$$

Solving for $z$ gives a canonical elliptic (circular) paraboloid:

$$z = \frac{(x - x_0)^2}{2(z_0 - d)} + \frac{(y - y_0)^2}{2(z_0 - d)} + \frac{z_0 + d}{2}$$
  • Vertex: Located halfway between the focal point and the plane at $(x_0, y_0, \frac{z_0 + d}{2})$.
  • Axis of symmetry: The line $x = x_0, y = y_0$ parallel to the $z$-axis.
  • Classification: Always an Elliptic Paraboloid (specifically a circular paraboloid because coefficients of $x^2$ and $y^2$ are identical).

Problem Statement

Find an equation of the surface that consists of all points equidistant from the point $(2, 2, 2)$ and the $xy$-plane ($z = 0$), and classify the resulting surface.

1
Formulate the Geometric Distance Conditions

Let $P(x, y, z)$ be an arbitrary point lying on the unknown surface:

  • The Euclidean distance from $P(x, y, z)$ to the fixed point $F(2, 2, 2)$ is: $$d_1 = \sqrt{(x - 2)^2 + (y - 2)^2 + (z - 2)^2}$$
  • The perpendicular distance from $P(x, y, z)$ to the $xy$-plane (equation $z = 0$) is: $$d_2 = |z - 0| = |z|$$
2

Set $d_1 = d_2$ and square both sides to eliminate the radical and absolute value:

$$(x - 2)^2 + (y - 2)^2 - 4z + 4 = 0$$

4. Traces & True/False Analysis of Quadric Surfaces

The most challenging conceptual problems on KFUPM exams present multi-part True/False statements evaluating the geometric cross-sections (called traces) of quadric surfaces in coordinate planes and parallel slicing planes (Term 253 Q2, Term 241 Q3, Term 231 Q18, Term 221 Q4, Term 221 Q5).

Rigorous Protocol for Trace Analysis

The trace of a surface in a plane is the 2D curve formed by the intersection of the surface with that plane:

  • Horizontal Traces: Set $z = k$ (planes parallel to the $xy$-plane). If $k = 0$, it is the trace in the $xy$-plane.
  • Vertical Traces ($y = k$): Set $y = k$ (planes parallel to the $xz$-plane). If $k = 0$, it is the trace in the $xz$-plane.
  • Vertical Traces ($x = k$): Set $x = k$ (planes parallel to the $yz$-plane). If $k = 0$, it is the trace in the $yz$-plane.

Algebraic Criteria for Traces

After substituting a constant plane slice (e.g., $z = k$), inspect the resulting 2D equation in the remaining two variables:

  • $Au^2 + Bv^2 = C$ with $A, B, C > 0 \implies$ Ellipse (or circle if $A = B$).
  • $Au^2 + Bv^2 = 0$ with $A, B > 0 \implies$ Single Point $(0, 0)$ (degenerate ellipse/cone vertex).
  • $Au^2 + Bv^2 = C$ with $A, B > 0$ and $C < 0 \implies$ Empty Set $\emptyset$ (no real points exist).
  • $Au^2 - Bv^2 = 0$ with $A, B > 0 \implies$ Pair of Intersecting Lines $u = \pm \sqrt{B/A} v$.
  • $Au^2 - Bv^2 = C$ with $C \neq 0 \implies$ Hyperbola.
  • $u = Av^2 + C \implies$ Parabola.

Worked Example 2: True/False Trace Analysis of an Elliptic Paraboloid

Problem Statement

Which one of the following statements is FALSE about the graph of the equation:

$$4x^2 - 4y + z^2 = 0$$
  • A. It is an elliptic paraboloid.
  • B. Its trace in the plane $y = -1$ is an ellipse.
  • C. Its trace in the plane $y = 1$ is an ellipse.
  • D. Its trace in the $xy$-plane is a parabola.
  • E. Its trace in the $xz$-plane is the origin.
Final Answer

Final Answer: Statement B is FALSE ("Its trace in the plane $y = -1$ is an ellipse")

Step-by-Step Solution
1
Rewrite in Standard Canonical Form

Isolate the linear variable $4y$ and divide through by $4$:

$$4y = 4x^2 + z^2 \iff y = x^2 + \frac{z^2}{4}$$

Variable $y$ is linear while $x$ and $z$ appear as squared terms with positive coefficients. Thus, the surface is an elliptic paraboloid opening along the positive $y$-axis with vertex at $(0,0,0)$. Statement A is TRUE.

2
Analyze Trace in Plane $y = -1$ (Testing Statement B)

Substitute $y = -1$ into the standard equation:

$$-1 = x^2 + \frac{z^2}{4}$$

Because $x^2 \ge 0$ and $\frac{z^2}{4} \ge 0$ for all real numbers $x, z$, their sum must be $\ge 0$. The sum of two non-negative terms can never equal $-1$.

Therefore, there are no real solutions $(x, z)$. The trace is the empty set $\emptyset$, NOT an ellipse! Statement B is FALSE.

3

1. Shifted Quadric Surfaces & Completing the Square

In Part 1 of Section 12.6 (Syllabus 11.6), we studied standard quadric surfaces centered at the origin $(0,0,0)$.

In general, a second-degree polynomial equation in three variables $x, y, z$ has the algebraic form:

$$Ax^2 + By^2 + Cz^2 + Dx + Ey + Fz + G = 0$$

When linear terms ($Dx, Ey, Fz$) are present alongside quadratic terms ($Ax^2, By^2, Cz^2$), the quadric surface is shifted (translated) so that its center or vertex is located at a shifted point $C(h, k, l)$ instead of $(0,0,0)$.

Systematic Recipe for Completing the Square

  1. Group terms by variable: Collect $(Ax^2 + Dx)$, $(By^2 + Ey)$, and $(Cz^2 + Fz)$ together, moving the constant $G$ to the right-hand side (RHS).
  2. Factor out leading coefficients: Before completing the square, ensure the squared term inside the parentheses has a coefficient of $+1$. For example, factor $-2y^2 + 4y$ as $-2(y^2 - 2y)$.
  3. Complete the square: For each expression $u^2 + bu$, add and subtract $left( rac{b}{2} ight)^2$: $$u^2 + bu = left(u + rac{b}{2} ight)^2 - left( rac{b}{2} ight)^2$$ Remember to multiply the subtracted number by the outer factored coefficient when balancing the equation.
  4. Normalize to Standard Form: Divide both sides by the resulting constant on the RHS so the RHS equals $1$ (for ellipsoids and hyperboloids) or $0$ (for cones). Read off the center/vertex $(h, k, l)$ and identify the surface type by checking signs.

3. Curve of Intersection of Quadric Surface with a Plane

When a 3D surface is intersected by a plane, the resulting curve of intersection in $mathbb{R}^3$ is found by solving the surface and plane equations simultaneously.

4. Radical Equations & Half-Quadric Surfaces

When an equation is written with an isolated variable set equal to a square root, it represents only half of a quadric surface because the square root is non-negative ($sqrt{dots} ge 0$).

  • $z = +sqrt{dots} implies z ge 0$ (upper half only).
  • $z = -sqrt{dots} implies z le 0$ (lower half only).
  • $y = +sqrt{dots} implies y ge 0$ (right half only).
  • Squaring both sides eliminates the radical and recovers the full quadric surface, but you must attach the inequality restriction!

1. Functions of Several Variables & Natural Domain Rules

A function of two variables $z = f(x, y)$ assigns to each ordered pair $(x, y)$ in a set $D subseteq mathbb{R}^2$ exactly one real number $f(x, y)$. The set $D$ is called the domain, and the set of all resulting output values ${f(x, y) mid (x, y) in D}$ is the range.

Complete Rules for Finding the Natural Domain

Unless explicitly specified otherwise, the natural domain consists of all points in $mathbb{R}^2$ or $mathbb{R}^3$ for which the formula produces a real output. Check every component for algebraic restrictions:

  1. Denominators: Cannot equal zero: $ rac{P(x,y)}{Q(x,y)} implies Q(x, y) eq 0$.
  2. Even Radicals: The expression inside $sqrt[2n]{g(x,y)}$ must be non-negative: $g(x, y) ge 0$. (If the radical is in a denominator, strictly positive: $g(x, y) > 0$).
  3. Logarithms: The argument of $ln(g(x, y))$ must be strictly positive: $g(x, y) > 0$.
  4. Inverse Sine & Cosine ($arcsin, arccos$): $$arcsin(u) ext{ and } arccos(u) implies -1 le u le 1$$ For $f(x,y) = arccos(g(x,y))$, you must enforce $-1 le g(x,y) le 1$.
  5. Inverse Tangent ($arctan$):
    $arctan(u)$ is defined for all real numbers $u in (-infty, infty)$. Therefore, $arctan(g(x,y))$ introduces no restriction of its own; its domain is simply the domain of $g(x,y)$!
  6. Boundary conventions: Solid lines/curves represent boundaries included ($le, ge$), while dashed/dotted curves indicate boundaries excluded ($<, >, eq$).

1. Multivariable Limits & Direct Substitution

We write $lim_{(x, y) o (a, b)} f(x, y) = L$ if the values of $f(x, y)$ can be made arbitrarily close to $L$ whenever $(x, y)$ is sufficiently close to $(a, b)$, approaching from any direction and along any path in the domain of $f$.

  • Direct Substitution: If $f(x, y)$ is a polynomial, rational function, exponential, or trigonometric combination whose denominator is non-zero at $(a, b)$, the limit is evaluated by direct substitution: $lim_{(x,y) o(a,b)} f(x,y) = f(a,b)$.
  • Indeterminate Form $ rac{0}{0}$: If direct substitution produces $ rac{0}{0}$, the limit may exist or it may not. You must deploy rigorous tools: the Two-Path Test (to show DNE), or Polar Coordinates / Squeeze Theorem / Rationalization (to prove existence).

2. The Two-Path Test & Degree Balancing for Non-Existence

The Two-Path Test: If $f(x, y) o L_1$ as $(x, y) o (a, b)$ along a path $C_1$, and $f(x, y) o L_2$ along another path $C_2$, with $L_1 eq L_2$, then:

$$lim_{(x, y) o (a, b)} f(x, y) quad ext{does not exist (DNE)}.$$

The Straight-Line Trap vs Degree Balancing

Testing along linear paths $y = mx$ is convenient, but equal limits along all straight lines DOES NOT prove the limit exists!

When the denominator contains terms of unequal powers, such as $x^2 + y^4$ or $x^4 + y^2$, straight lines $y = mx$ make the lower-degree term dominate, causing the limit to appear to be $0$ for every straight line! To expose non-existence, you must balance the degrees:

  • If the denominator is $x^2 + y^4$, set $x = k y^2 implies x^2 = k^2 y^4$, making both terms of degree $4$!
  • If the denominator is $x^4 + y^2$, set $y = k x^2 implies y^2 = k^2 x^4$, making both terms of degree $4$!
Example

Worked Example 1: Degree Balancing with Parabolic Path $x = ky^2$

Problem

Determine whether the limit exists or show that it does not exist:

$$lim_{(x, y) o (0, 0)} rac{x y^2}{x^2 + y^4}$$
Final Answer

The limit does not exist (DNE).

Step-by-Step Solution

Step 1: Test along linear paths $y = mx$.

$$lim_{x o 0} rac{x (mx)^2}{x^2 + (mx)^4} = lim_{x o 0} rac{m^2 x^3}{x^2(1 + m^4 x^2)} = lim_{x o 0} rac{m^2 x}{1 + m^4 x^2} = rac{0}{1} = 0$$

The limit is $0$ along every straight line through the origin. However, this does not prove the limit exists!

Step 2: Balance the degrees in the denominator using $x = k y^2$.

Substitute $x = k y^2$ as $y o 0$:

$$lim_{y o 0} rac{(k y^2) y^2}{(k y^2)^2 + y^4} = lim_{y o 0} rac{k y^4}{k^2 y^4 + y^4} = lim_{y o 0} rac{k}{k^2 + 1} = rac{k}{k^2 + 1}$$

Step 3: Conclude by the Two-Path Test.

  • Along the parabolic path $x = y^2$ ($k = 1$): limit is $ rac{1}{1^2 + 1} = rac{1}{2}$.
  • Along the path $x = -y^2$ ($k = -1$): limit is $ rac{-1}{(-1)^2 + 1} = - rac{1}{2}$.
  • Along the line $x = 0$ ($k = 0$): limit is $0$.

Since the limit depends on the choice of path ($1/2 eq 0$), by the Two-Path Test, the limit does not exist.

3. Proving Limits Exist: Polar Coordinates & Squeeze Theorem

To definitively prove that a limit as $(x, y) o (0, 0)$ exists and find its value, two primary techniques are used:

Technique 1: Polar Coordinates Substitution

Set $x = rcos heta$ and $y = rsin heta$, with $x^2 + y^2 = r^2$. Since $(x, y) o (0, 0) iff r o 0^+$, substitute and simplify:

$$f(x, y) = f(rcos heta, rsin heta) = r^p g( heta)$$

If $p > 0$ and $g( heta)$ is bounded (e.g., $|g( heta)| le M$ for all $ heta$), then:

$$lim_{(x, y) o (0, 0)} f(x, y) = lim_{r o 0^+} r^p g( heta) = 0$$

Technique 2: The Squeeze (Sandwich) Theorem

If $g(x, y) le f(x, y) le h(x, y)$ for all $(x, y)$ in an open disk around $(a, b)$, and $lim_{(x,y) o(a,b)} g(x,y) = lim_{(x,y) o(a,b)} h(x,y) = L$, then $lim_{(x,y) o(a,b)} f(x,y) = L$.

Useful Algebraic Bounds:

  • $0 le rac{x^2}{x^2 + y^2} le 1$ and $0 le rac{y^2}{x^2 + y^2} le 1$
  • $|x| le sqrt{x^2 + y^2} = r$ and $|y| le sqrt{x^2 + y^2} = r$
  • $|sin u| le |u|$ and $|sin u| le 1$

5. The Strict Open-Disk Domain Requirement (Thomas' Calculus Sec 13.2 / KFUPM Exam 252)

A profound theoretical subtlety in multivariable calculus that frequently appears on advanced university exams (such as KFUPM Exam 252, Question 8) concerns the domain requirement in the definition of a limit.

The Textbook Definition (Thomas' Calculus, Section 13.2)

Definition: We say that a function $f(x, y)$ has limit $L$ as $(x, y) o (x_0, y_0)$ if $f$ is defined on an open disk centered at $(x_0, y_0)$, except possibly at $(x_0, y_0)$ itself, and for every $ arepsilon > 0$, there exists $delta > 0$ such that $|f(x, y) - L| < arepsilon$ whenever $0 < sqrt{(x - x_0)^2 + (y - y_0)^2} < delta$.

Why Does $lim_{(x, y) o (0, 0)} rac{x - y}{sqrt{x} - sqrt{y}}$ NOT Exist Under the Strict Definition?

  1. Domain Restriction: The expression requires $sqrt{x}$ and $sqrt{y}$ to be real, so $x ge 0$ and $y ge 0$, and the denominator requires $x eq y$. Thus, the domain of $f$ is strictly contained within the first quadrant.
  2. Failure of the Open-Disk Requirement: Every open disk centered at $(0, 0)$ of radius $delta > 0$ contains points with $x < 0$ or $y < 0$ (lying in Quadrants II, III, and IV). At all these points, $f(x, y)$ is completely undefined!
  3. Conclusion: Because there is no punctured open disk centered at $(0, 0)$ that lies within the domain of $f$, the unrestricted limit does not exist (DNE) according to the formal definition! (It only exists if explicitly restricted to the first quadrant).

6. Continuity of Multivariable Functions

A function $f(x, y)$ is continuous at a point $(a, b)$ if:

  1. $f(a, b)$ is defined.
  2. $lim_{(x, y) o (a, b)} f(x, y)$ exists.
  3. $lim_{(x, y) o (a, b)} f(x, y) = f(a, b)$.

A function is continuous on a region $R$ if it is continuous at every point in $R$. Compositions, sums, differences, products, and quotients (where denominator $ eq 0$) of continuous functions are continuous.

1. Definition & Geometric Meaning of Partial Derivatives

For a function of two variables $z = f(x, y)$:

  • The partial derivative with respect to $x$, denoted $ rac{partial f}{partial x}$ or $f_x(x, y)$, is computed by treating $y$ as a constant and differentiating with respect to $x$: $$f_x(x, y) = lim_{h o 0} rac{f(x + h, y) - f(x, y)}{h}$$
  • The partial derivative with respect to $y$, denoted $ rac{partial f}{partial y}$ or $f_y(x, y)$, is computed by treating $x$ as a constant and differentiating with respect to $y$: $$f_y(x, y) = lim_{h o 0} rac{f(x, y + h) - f(x, y)}{h}$$

Geometric Interpretation as Trace Slopes

  • Slice by the vertical plane $y = b$: The intersection with the surface $z = f(x, y)$ forms a curve $C_1$. The slope of the tangent line to $C_1$ at the point $(a, b, f(a, b))$ in the direction of the positive $x$-axis is precisely $f_x(a, b)$.
  • Slice by the vertical plane $x = a$: The intersection forms a curve $C_2$. The slope of the tangent line to $C_2$ at $(a, b, f(a, b))$ in the direction of the positive $y$-axis is precisely $f_y(a, b)$.

2. Higher Partial Derivatives & Clairaut's Theorem

A function $f(x, y)$ has four second-order partial derivatives:

$$f_{xx} = rac{partial^2 f}{partial x^2}, quad f_{yy} = rac{partial^2 f}{partial y^2}$$ $$f_{xy} = (f_x)_y = rac{partial}{partial y}left( rac{partial f}{partial x} ight) = rac{partial^2 f}{partial y partial x}$$ $$f_{yx} = (f_y)_x = rac{partial}{partial x}left( rac{partial f}{partial y} ight) = rac{partial^2 f}{partial x partial y}$$

Clairaut's Theorem (Equality of Mixed Partials)

If $f(x, y)$ and its partial derivatives $f_x, f_y, f_{xy}$, and $f_{yx}$ are defined and continuous on an open disk containing $(a, b)$, then the mixed second partial derivatives are equal:

$$f_{xy}(a, b) = f_{yx}(a, b)$$

Extension to Higher Orders: The equality of mixed partials extends to third and higher-order derivatives as long as the continuity hypothesis holds. For example:

$$f_{xxy} = f_{xyx} = f_{yxx} quad ext{and} quad f_{xyy} = f_{yxy} = f_{yyx}$$

Strategic Exam Shortcut: When asked to compute a mixed partial such as $ rac{partial^4 f}{partial x^2 partial y^2}$, you can differentiate in whichever order makes terms drop to zero fastest!

3. Partial Derivatives of Integral Functions (Leibniz Rule / FTC)

When a multivariable function is defined as a definite integral with variable limits of integration:

$$f(x, y) = int_{u(x, y)}^{v(x, y)} g(t),dt$$

its partial derivatives are found by combining the Fundamental Theorem of Calculus (FTC) with the Multivariable Chain Rule (known as the Leibniz Integral Rule):

$$ rac{partial f}{partial x} = g(v(x, y)) cdot rac{partial v}{partial x} - g(u(x, y)) cdot rac{partial u}{partial x}$$ $$ rac{partial f}{partial y} = g(v(x, y)) cdot rac{partial v}{partial y} - g(u(x, y)) cdot rac{partial u}{partial y}$$

Key Operating Rules

  • When taking $ rac{partial}{partial x}$, treat $y$ as a constant. If a limit of integration contains only $y$ (such as $u(x, y) = y$), its partial derivative with respect to $x$ is $ rac{partial u}{partial x} = 0$!
  • When taking $ rac{partial}{partial y}$, treat $x$ as a constant. If a limit of integration contains only $x$ (such as $v(x, y) = x^2$), its partial derivative with respect to $y$ is $ rac{partial v}{partial y} = 0$!
  • Never attempt to evaluate an impossible anti-derivative (like $int cos(t^2),dt$ or $int e^{-t^2},dt$); the Fundamental Theorem of Calculus differentiates the integral directly!
Example

4. Verifying Solutions to Partial Differential Equations (PDEs)

A Partial Differential Equation (PDE) involves an unknown function of two or more variables and its partial derivatives. Famous physical PDEs include:

  • Laplace's Equation: $ rac{partial^2 u}{partial x^2} + rac{partial^2 u}{partial y^2} = 0 iff u_{xx} + u_{yy} = 0$ (solutions are called harmonic functions; models steady-state heat, electrostatic potentials, and fluid flow).
  • The Wave Equation: $ rac{partial^2 u}{partial t^2} = c^2 rac{partial^2 u}{partial x^2} iff u_{tt} = c^2 u_{xx}$ (describes vibrating strings, sound waves, and light).
  • The Heat (Diffusion) Equation: $ rac{partial u}{partial t} = k rac{partial^2 u}{partial x^2} iff u_t = k u_{xx}$.

To verify that a given function $u$ solves a PDE, compute the required partial derivatives and show that substituting them makes the equation identically $0$.

Example

Worked Example 6: Verifying that a Function Satisfies Laplace's Equation

Problem

Show that the function $u(x, y) = e^x sin(y)$ satisfies Laplace's equation:

$$u_{xx} + u_{yy} = 0$$
Final Answer

$u_{xx} = e^x sin(y)$ and $u_{yy} = -e^x sin(y) implies u_{xx} + u_{yy} = 0$. Thus, $u(x, y)$ is a harmonic function.

Step-by-Step Solution

Step 1: Compute first and second partials with respect to $x$.

$$u_x = rac{partial}{partial x}(e^x sin y) = e^x sin y$$ $$u_{xx} = rac{partial}{partial x}(e^x sin y) = e^x sin y$$

Step 2: Compute first and second partials with respect to $y$.

$$u_y = rac{partial}{partial y}(e^x sin y) = e^x cos y$$ $$u_{yy} = rac{partial}{partial y}(e^x cos y) = e^x(-sin y) = -e^x sin y$$

Step 3: Substitute into Laplace's equation.

$$u_{xx} + u_{yy} = e^x sin y + (-e^x sin y) = 0$$

The equation holds identically for all $(x, y) in mathbb{R}^2$, confirming that $u$ is a solution.

1. Linearization & Local Linear Approximation

In single-variable calculus, the tangent line approximates a curve near a point. In multivariable calculus, the tangent plane approximates a smooth surface $z = f(x, y)$ near a base point $(a, b)$. This linear function is called the linearization of $f$ at $(a, b)$.

1.1 Linearization Formula in Two Variables

The linearization $L(x, y)$ of a differentiable function $f(x, y)$ at the base point $(a, b)$ is defined as:

$$L(x, y) = f(a, b) + f_x(a, b)(x - a) + f_y(a, b)(y - b)$$

The corresponding local linear approximation is:

$$f(x, y) approx L(x, y) = f(a, b) + f_x(a, b)(x - a) + f_y(a, b)(y - b)$$

Geometrically, $z = L(x, y)$ is the exact equation of the tangent plane to the surface $z = f(x, y)$ at the point of tangency $(a, b, f(a, b))$.

1.2 Linearization in Three Variables

For a function of three independent variables $w = f(x, y, z)$ at base point $(a, b, c)$, the linearization is:

$$L(x, y, z) = f(a, b, c) + f_x(a, b, c)(x - a) + f_y(a, b, c)(y - b) + f_z(a, b, c)(z - c)$$

1.3 Strategy for Approximation Questions

  1. Identify the Target Point: Note the given values $(x, y)$ where the function value is required (e.g., $(3.1, 0.2)$).
  2. Select the Base Point $(a, b)$: Pick a nearby point $(a, b)$ where $f(a, b)$ and its partial derivatives $f_x(a, b), f_y(a, b)$ evaluate to clean, exact numbers.
  3. Calculate Displacements: Compute $Delta x = x - a$ and $Delta y = y - b$.
  4. Evaluate Linearization: Plug values into $L(x, y) = f(a, b) + f_x(a, b)Delta x + f_y(a, b)Delta y$.

2. The Total Differential & Increment Approximation

For independent variables $x$ and $y$, the differentials are defined as $dx = Delta x$ and $dy = Delta y$. The total differential represents the principal linear part of the change in the dependent variable.

2.1 Total Differential Definitions

For a function of two variables $z = f(x, y)$, the total differential $dz$ (or $df$) is:

$$dz = df = f_x(x, y),dx + f_y(x, y),dy = rac{partial z}{partial x} dx + rac{partial z}{partial y} dy$$

For a function of three variables $w = f(x, y, z)$:

$$dw = df = f_x,dx + f_y,dy + f_z,dz = rac{partial w}{partial x}dx + rac{partial w}{partial y}dy + rac{partial w}{partial z}dz$$

2.2 The Fundamental Increment Approximation

The true change in $z$ between $(x_0, y_0)$ and $(x_0 + Delta x, y_0 + Delta y)$ is the increment:

$$Delta z = f(x_0 + Delta x, y_0 + Delta y) - f(x_0, y_0)$$

For small increments $Delta x$ and $Delta y$:

$$Delta z approx dz = f_x(x_0, y_0),Delta x + f_y(x_0, y_0),Delta y$$

This allows us to estimate how small errors or shifts in independent inputs affect the output value without recomputing the full complicated function.

3. Differentiability & The Continuity Criterion

Unlike single-variable calculus where the existence of $f'(x)$ is equivalent to differentiability, in multivariable calculus the mere existence of partial derivatives $f_x$ and $f_y$ does NOT guarantee that the function is differentiable or even continuous!

3.1 Formal Definition of Differentiability

A function $z = f(x, y)$ is differentiable at $(a, b)$ if $Delta z$ can be expressed in the form:

$$Delta z = f_x(a, b)Delta x + f_y(a, b)Delta y + arepsilon_1 Delta x + arepsilon_2 Delta y$$

where $ arepsilon_1 o 0$ and $ arepsilon_2 o 0$ as $(Delta x, Delta y) o (0, 0)$. Equivalently:

$$lim_{(Delta x, Delta y) o (0, 0)} rac{Delta z - [f_x(a, b)Delta x + f_y(a, b)Delta y]}{sqrt{(Delta x)^2 + (Delta y)^2}} = 0$$

3.2 Sufficient Condition for Differentiability (Theorem)

If the first partial derivatives $f_x$ and $f_y$ exist in an open region containing $(a, b)$ and are continuous at $(a, b)$, then $f(x, y)$ is differentiable at $(a, b)$.

3.3 Key Relationship: Hierarchy of Regularity

$$ ext{Continuous Partials } (f_x, f_y in C^0) implies ext{Differentiable } f implies ext{Continuous } f$$

4. Relative & Percentage Error Estimation

When measurements of physical quantities are subject to small measurement errors, differentials allow us to determine how these errors propagate into computed formulas.

4.1 Definitions of Error Types

  • Absolute Error in $x$: $|Delta x| approx |dx|$
  • Relative Error in $x$: $ rac{|Delta x|}{x} approx rac{|dx|}{x}$
  • Percentage Error in $x$: $ rac{|Delta x|}{x} imes 100%$
  • Maximum Estimated Absolute Error in $z = f(x, y)$ (Triangle Inequality): $$|dz| le |f_x|,|Delta x| + |f_y|,|Delta y|$$

4.2 The Logarithmic Differentiation Shortcut

For formulas consisting of products, quotients, and powers, dividing the total differential $df$ by $f$ is identical to taking the total differential of the natural logarithm $ln f$:

$$ rac{df}{f} = d(ln f)$$

This provides an instantaneous shortcut for relative error propagation:

  • Rectangular Box $V = xyz$: $$ln V = ln x + ln y + ln z implies rac{dV}{V} = rac{dx}{x} + rac{dy}{y} + rac{dz}{z}$$ If each dimension has a $1%$ error, the maximum error in volume is $1% + 1% + 1% = 3%$.
  • Cylinder Volume $V = pi r^2 h$: $$ln V = ln pi + 2ln r + ln h implies rac{dV}{V} = 2 rac{dr}{r} + rac{dh}{h}$$ A $2%$ error in radius and $1.5%$ error in height gives a maximum volume error of $2(2%) + 1.5% = 5.5%$.
  • Sphere Volume $V = rac{4}{3}pi r^3$: $$ rac{dV}{V} = 3 rac{dr}{r}$$

Explanation

1. Chain Rule: Case 1 (Single Independent Variable)

When the inputs of a multivariable function depend on a single independent parameter $t$ (such as time along a parametric space curve), the composition becomes a single-variable function of $t$.

1.1 Two Intermediate Variables

If $z = f(x, y)$ is differentiable and $x = g(t), y = h(t)$ are differentiable functions of $t$, then $z$ is a function of $t$ and its ordinary derivative is:

$$ rac{dz}{dt} = rac{partial z}{partial x} rac{dx}{dt} + rac{partial z}{partial y} rac{dy}{dt}$$

1.2 Three Intermediate Variables (Vector Formulation)

If $w = f(x, y, z)$ where $mathbf{r}(t) = langle x(t), y(t), z(t) angle$ is a smooth space curve, then:

$$ rac{dw}{dt} = rac{partial w}{partial x} rac{dx}{dt} + rac{partial w}{partial y} rac{dy}{dt} + rac{partial w}{partial z} rac{dz}{dt} = abla w cdot mathbf{r}'(t)$$

Physical Interpretation: The instantaneous rate of change of a field quantity $w$ (e.g., temperature, potential) experienced by an observer moving with velocity $mathbf{v}(t) = mathbf{r}'(t)$ is the dot product of the gradient field with velocity.

2. Chain Rule: Case 2 & Dependency Tree Diagrams

When the intermediate variables depend on two or more independent variables (e.g., $s$ and $t$), partial derivatives are required with respect to each independent variable.

2.1 Two Intermediate & Two Independent Variables

If $z = f(x, y)$ where $x = g(s, t)$ and $y = h(s, t)$:

$$ rac{partial z}{partial s} = rac{partial z}{partial x} rac{partial x}{partial s} + rac{partial z}{partial y} rac{partial y}{partial s}$$ $$ rac{partial z}{partial t} = rac{partial z}{partial x} rac{partial x}{partial t} + rac{partial z}{partial y} rac{partial y}{partial t}$$

2.2 Tree Diagram Rules

  1. Root (Top): The dependent variable ($z$ or $w$).
  2. Branches (Middle): All intermediate variables ($x, y, dots$).
  3. Leaves (Bottom): The independent variables ($s, t, dots$).
  4. Multiplication Along Paths: Multiply the partial derivatives along each connected path from root to target leaf.
  5. Sum Across Branches: Add the path products for all paths ending at the chosen independent variable.

3. Implicit Differentiation Formulas

When a relation is given implicitly in the form $F(x, y) = 0$ or $F(x, y, z) = 0$, the multivariable chain rule provides exact formulas for derivatives without needing to solve for the dependent variable explicitly.

3.1 Single-Variable Function $y = f(x)$ Defined by $F(x, y) = 0$

Differentiating $F(x, y) = 0$ with respect to $x$ using the chain rule:

$$ rac{partial F}{partial x} rac{dx}{dx} + rac{partial F}{partial y} rac{dy}{dx} = 0 implies F_x + F_y rac{dy}{dx} = 0$$ $$ rac{dy}{dx} = - rac{F_x}{F_y} qquad (F_y eq 0)$$

3.2 Multivariable Function $z = f(x, y)$ Defined by $F(x, y, z) = 0$

Differentiating $F(x, y, z) = 0$ partially with respect to $x$ (holding $y$ constant):

$$F_x rac{partial x}{partial x} + F_y rac{partial y}{partial x} + F_z rac{partial z}{partial x} = 0 implies F_x(1) + F_y(0) + F_z rac{partial z}{partial x} = 0$$ $$ rac{partial z}{partial x} = - rac{F_x}{F_z} qquad (F_z eq 0)$$

Similarly, differentiating partially with respect to $y$ (holding $x$ constant):

$$ rac{partial z}{partial y} = - rac{F_y}{F_z} qquad (F_z eq 0)$$

3.3 The Golden Rule for KFUPM Exams

NEVER FORGET THE NEGATIVE SIGN! The negative sign appears because $F_x$ or $F_y$ is moved to the opposite side of the equation:

$$F_x + F_z rac{partial z}{partial x} = 0 implies F_z rac{partial z}{partial x} = -F_x implies rac{partial z}{partial x} = - rac{F_x}{F_z}$$

1. Directional Derivatives & The Gradient Vector

Partial derivatives $f_x$ and $f_y$ measure the rate of change of $f(x, y)$ parallel to the coordinate axes $mathbf{i}$ and $mathbf{j}$. The directional derivative generalizes this to measure the instantaneous rate of change in any arbitrary direction.

1.1 Limit Definition of Directional Derivative

The directional derivative of $f(x, y)$ at $(x_0, y_0)$ in the direction of a unit vector $mathbf{u} = langle a, b angle$ is:

$$D_{mathbf{u}} f(x_0, y_0) = lim_{h o 0} rac{f(x_0 + ha, y_0 + hb) - f(x_0, y_0)}{h}$$

1.2 The Gradient Vector Operator ($ abla$)

The gradient of a scalar function is a vector whose components are its first-order partial derivatives:

$$ ext{In 2D: } abla f(x, y) = leftlangle rac{partial f}{partial x}, rac{partial f}{partial y} ight angle = f_xmathbf{i} + f_ymathbf{j}$$ $$ ext{In 3D: } abla f(x, y, z) = leftlangle rac{partial f}{partial x}, rac{partial f}{partial y}, rac{partial f}{partial z} ight angle = f_xmathbf{i} + f_ymathbf{j} + f_zmathbf{k}$$

1.3 The Fundamental Dot Product Formula

For any differentiable function, the directional derivative is calculated as the dot product:

$$D_{mathbf{u}} f = abla f cdot mathbf{u}$$

1.4 THE MANDATORY EXAM RULE: Normalization

$mathbf{u}$ MUST ALWAYS BE A UNIT VECTOR ($|mathbf{u}| = 1$)!

If a question provides a general vector $mathbf{v}$, you MUST FIRST NORMALIZE IT:

$$mathbf{u} = rac{mathbf{v}}{|mathbf{v}|}$$

If you take $ abla f cdot mathbf{v}$ without dividing by $|mathbf{v}|$, your answer will be scaled by $|mathbf{v}|$, leading to an immediate deduction!

3. Maximum, Minimum & Zero Rates of Change

Using the geometric definition of the dot product where $ heta$ is the angle between $ abla f$ and the unit vector $mathbf{u}$:

  • Occurs when $cos heta = 1 implies heta = 0$ (direction of the gradient vector $ abla f$).
  • Maximum Value: $max D_{mathbf{u}} f = | abla f|$
  • Direction of Maximum Change: $mathbf{u}_{max} = rac{ abla f}{| abla f|}$

3.2 Minimum Rate of Change (Steepest Descent)

  • Occurs when $cos heta = -1 implies heta = pi$ (opposite direction $- abla f$).
  • Minimum Value: $min D_{mathbf{u}} f = -| abla f|$
  • Direction of Minimum Change: $mathbf{u}_{min} = - rac{ abla f}{| abla f|}$

3.3 Zero Rate of Change (No Change)

  • Occurs when $cos heta = 0 implies heta = rac{pi}{2}$ or $ rac{3pi}{2}$ (orthogonal/perpendicular to $ abla f$).
  • Condition: $ abla f cdot mathbf{u} = 0$.

4. Normal Vectors & Tangent Lines to Level Curves

Along any level curve $f(x, y) = c$, the function value remains constant. Consequently, the rate of change of $f$ in the tangential direction along the level curve is zero ($D_{mathbf{T}} f = 0$).

4.1 Gradient is Perpendicular to Level Curves

Because $D_{mathbf{T}} f = abla f cdot mathbf{T} = 0$, the gradient vector $ abla f(x_0, y_0)$ is always perpendicular (normal) to the level curve $f(x, y) = c$ passing through $(x_0, y_0)$.

4.2 Unit Normal Vector to a Level Curve

$$mathbf{n} = pm rac{ abla f(x_0, y_0)}{| abla f(x_0, y_0)|}$$

4.3 Equation of the Tangent Line to Level Curve

The tangent line to the level curve at $(x_0, y_0)$ has normal vector $ abla f(x_0, y_0) = langle f_x, f_y angle$:

$$ abla f(x_0, y_0) cdot langle x - x_0, y - y_0 angle = 0$$ $$f_x(x_0, y_0)(x - x_0) + f_y(x_0, y_0)(y - y_0) = 0$$

1. Tangent Planes & Normal Lines to Level Surfaces $F(x, y, z) = k$

Just as the gradient $ abla f(x, y)$ is perpendicular to level curves in 2D, the 3D gradient vector $ abla F(x, y, z)$ is always perpendicular (normal) to the level surface $F(x, y, z) = k$ at any point $P(x_0, y_0, z_0)$.

1.1 Surface Normal Vector

For any point $P(x_0, y_0, z_0)$ on the smooth surface $F(x, y, z) = k$ where $ abla F(P) eq mathbf{0}$, the normal vector to the tangent plane is:

$$mathbf{n} = abla F(x_0, y_0, z_0) = langle F_x(x_0, y_0, z_0), ; F_y(x_0, y_0, z_0), ; F_z(x_0, y_0, z_0) angle$$

1.2 Equation of the Tangent Plane

The vector equation $mathbf{n} cdot langle x - x_0, y - y_0, z - z_0 angle = 0$ yields:

$$F_x(x_0, y_0, z_0)(x - x_0) + F_y(x_0, y_0, z_0)(y - y_0) + F_z(x_0, y_0, z_0)(z - z_0) = 0$$

1.3 Equations of the Normal Line

The normal line passes through $(x_0, y_0, z_0)$ parallel to the gradient vector $ abla F(x_0, y_0, z_0)$:

  • Parametric Form: $x = x_0 + F_x t, quad y = y_0 + F_y t, quad z = z_0 + F_z t$
  • Symmetric Form (if $F_x, F_y, F_z eq 0$): $$ rac{x - x_0}{F_x} = rac{y - y_0}{F_y} = rac{z - z_0}{F_z}$$

1.4 Explicit Surfaces $z = f(x, y)$ as Level Surfaces

If a surface is given explicitly as $z = f(x, y)$, define $F(x, y, z) = f(x, y) - z = 0$. Then:

$$ abla F = langle f_x, f_y, -1 angle implies f_x(x - x_0) + f_y(y - y_0) - (z - z_0) = 0$$

which recovers the familiar tangent plane equation $z - z_0 = f_x(x - x_0) + f_y(y - y_0)$.

Worked Example 1: Tangent Plane in Form $x + ay + bz + c = 0$ (Classic KFUPM Archetype)

Problem

If the equation of the tangent plane to the hyperboloid of two sheets:

$$z^2 - 2x^2 - 2y^2 = 12$$

at the point $P(1, -1, 4)$ is written in the standard form $x + ay + bz + c = 0$, find the value of $a + b + c$.

Final Answer

$x - y - 2z + 6 = 0 implies a = -1, ; b = -2, ; c = 6 implies a + b + c = 3$

Step-by-Step Solution

Step 1: Set up the level surface $F(x, y, z) = 0$.

$$F(x, y, z) = z^2 - 2x^2 - 2y^2 - 12 = 0$$

Verify point $P(1, -1, 4)$: $4^2 - 2(1)^2 - 2(-1)^2 = 16 - 2 - 2 = 12$ (verified).

Step 2: Calculate the gradient vector $ abla F$.

$$F_x = rac{partial}{partial x}(z^2 - 2x^2 - 2y^2 - 12) = -4x$$ $$F_y = rac{partial}{partial y}(z^2 - 2x^2 - 2y^2 - 12) = -4y$$ $$F_z = rac{partial}{partial z}(z^2 - 2x^2 - 2y^2 - 12) = 2z$$

Evaluate at $P(1, -1, 4)$:

$$ abla F(1, -1, 4) = langle -4(1), -4(-1), 2(4) angle = langle -4, 4, 8 angle$$

$$-4(x - 1) + 4(y - (-1)) + 8(z - 4) = 0$$ $$-4(x - 1) + 4(y + 1) + 8(z - 4) = 0$$

$$(x - 1) - (y + 1) - 2(z - 4) = 0$$ $$x - 1 - y - 1 - 2z + 8 = 0$$ $$x - y - 2z + 6 = 0$$

$$a = -1, quad b = -2, quad c = 6$$ $$a + b + c = (-1) + (-2) + 6 = 3$$

2. Horizontal & Parallel Tangent Planes

Questions involving parallel tangent planes test your understanding of proportional normal vectors.

2.1 Horizontal Tangent Planes

A plane is horizontal if and only if it is parallel to the $xy$-plane, which means its normal vector is parallel to $mathbf{k} = langle 0, 0, 1 angle$.

For a level surface $F(x, y, z) = k$, a tangent plane is horizontal precisely where:

$$F_x = 0 quad ext{and} quad F_y = 0 quad ext{with } F_z eq 0$$

2.2 Tangent Planes Parallel to a Given Plane $Ax + By + Cz = D$

Two planes are parallel if and only if their normal vectors are scalar multiples of each other. Therefore, the normal vector $ abla F(x, y, z)$ must satisfy:

$$ abla F(x, y, z) = lambda langle A, B, C angle iff egin{cases} F_x = lambda A \ F_y = lambda B \ F_z = lambda C end{cases}$$
  1. Express $x, y, z$ in terms of the scalar multiplier $lambda$.
  2. Substitute these expressions into the surface equation $F(x, y, z) = k$ to solve for $lambda$.
  3. Compute the tangency points $(x, y, z)$ and write the corresponding plane equations.

3. Tangent Line to the Curve of Intersection of Two Surfaces

When two smooth surfaces $F(x, y, z) = 0$ and $G(x, y, z) = 0$ intersect, their intersection forms a 3D curve $C$. At any point $P(x_0, y_0, z_0)$ on $C$, we can find the tangent line to the curve using cross products.

3.1 Direction Vector of the Tangent Line

The tangent line $L$ to curve $C$ at point $P$ must lie simultaneously in the tangent plane to $F$ at $P$ and in the tangent plane to $G$ at $P$:

  • $L$ lies in the tangent plane to $F implies L$ is perpendicular to $ abla F(P)$.
  • $L$ lies in the tangent plane to $G implies L$ is perpendicular to $ abla G(P)$.

Therefore, a direction vector $mathbf{v}$ for the tangent line is given by the cross product of the surface normals:

$$mathbf{v} = abla F(P) imes abla G(P)$$

3.2 Parametric Equations of the Tangent Line

$$mathbf{r}(t) = overrightarrow{OP} + t ( abla F(P) imes abla G(P))$$ $$x = x_0 + v_1 t, quad y = y_0 + v_2 t, quad z = z_0 + v_3 t qquad (-infty < t < infty)$$
